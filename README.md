## 📋 Exam Overview (312-38)

The CND v3 certification is a vendor-neutral, blue-team network defense credential focused on protecting, detecting, responding, and predicting across enterprise networks.

| Exam Detail | Information |
| :--- | :--- |
| **Exam Title** | Certified Network Defender (CND v3) |
| **Exam Code** | 312-38 |
| **Number of Questions** | 100 Questions |
| **Duration** | 4 Hours (240 Minutes) |
| **Passing Score** | ~70% (varies slightly by region) |
| **Exam Domains** | 6 Core Domains |
| **Typical Prep Time** | 4–8 Weeks |
| **Focus Areas** | Network perimeter security, endpoint hardening, incident response, cloud/wireless security, and threat intelligence |

## 🗺️ Additional CND v3 Exam Topics (Modules 6–20 — Optional Self-Study)

*Note: Our class covers **Modules 01–05** above. For classmates planning to sit for the full EC-Council 312-38 certification exam, the remaining CND v3 blueprint domains include:*

- **Endpoint & Application Security (Modules 06–09):** Linux Hardening, Mobile Devices, IoT Security (GSMA Guidelines, 4-Layer IoT Architecture), and Administrative Application Security (Defense in Breadth vs. Depth, Web Application Firewalls [WAF], URLScan for IIS).
- **Data Security (Module 10):** Business-Critical Data, Data-at-Rest vs. Data-in-Use vs. Data-in-Transit Encryption (SSL/TLS on Windows/SQL/Oracle, Digital Certificates), Data Masking, Backup/Retention, DLP, and Data Erasure/Destruction.
- **Virtual, Cloud & Wireless Security (Modules 11–13):** Network Virtualization (NV), SDN, NFV, Hypervisor/VLAN Hardening, Containers (Docker & Kubernetes Security), Cloud Shared Responsibility Model (AWS, Azure, GCP), and Wireless Defense (Adaptive WIPS, AirDefense, Wi-Fi Easy Connect/DPP).
- **Monitoring, Incident Response & Threat Intelligence (Modules 14–20):** Network Traffic & Log Monitoring, First Responder Incident Handling, Business Continuity & Disaster Recovery, Vulnerability & Privacy Impact Assessments (PIA/DPIA), Attack Surface Visualization (`ThreatPath`, `securiCAD`, `Skybox`), Indicators of Exposure (IoE), and AI/ML Threat Hunting (`SolarWinds SEM`, `ManageEngine Log360`).
